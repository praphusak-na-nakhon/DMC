# Remove P-SAR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the P-SAR/SAR feature, its assets, and every product-facing reference without changing retained DMC workflows.

**Architecture:** Remove P-SAR as three vertical slices: desktop surface and contracts, sidecar service and RPC, then bundled assets and product documentation. Each slice leaves desktop and sidecar tests runnable.

**Tech Stack:** React 18, TypeScript, Vitest, Python 3.11+, Pydantic 2, pytest, Tauri 2 packaging scripts

**Spec:** `docs/superpowers/specs/2026-09-04-local-first-byok-refactor-design.md`

## Global Constraints

- Preserve Graduation, Current Students, Form Converter, and Student Basic Info behavior.
- Remove P-SAR completely; do not retain a reusable package in this repository.
- Do not alter or commit the user's uncommitted `apps/sidecar/scripts/build_windows_bundle.ps1` probe fix. When this plan edits that file, stage only the P-SAR removal hunk and verify the probe hunk remains unstaged.
- Do not commit `P-SAR-form.docx`, generated reports, local databases, or build output elsewhere as a backup.
- References in the approved design and implementation-plan history are intentionally retained.
